# 🐸 CandyFrog Game

CandyFrog adalah game sederhana dan seru yang dibuat menggunakan Greenfoot. Dalam game ini, pemain mengendalikan seekor kodok yang bergerak ke kanan dan kiri untuk menangkap permen yang berjatuhan. Setiap permen yang berhasil ditangkap akan menambah poin, namun pemain harus berhati-hati karena barang-barang aneh selain permen dapat mengurangi nyawa.

## 🛠️ Teknologi yang Digunakan

- Greenfoot

- Bahasa pemrograman Java

## 🚀 Cara Menjalankan Proyek
1. Pastikan kamu sudah menginstal **Greenfoot**.  
   > Unduh di: [https://www.greenfoot.org/download](https://www.greenfoot.org/download)

2. Clone repository ini:
   ```bash
   git clone https://github.com/dhnnnn/CandyFrog.git
  3. Buka folder proyek di Greenfoot.
  4. Klik tombol **Run** untuk mulai bermain. 🕹️

# 🎯 Tujuan Game
- Mengumpulkan permen sebanyak mungkin

- Melatih refleks dan ketepatan pemain

- Mendapatkan skor tertinggi

# 📜 Peraturan Game
1. Kodok hanya dapat bergerak ke kanan dan kiri.

2. Permen menambah poin.

3. Barang selain permen mengurangi nyawa.

4. Game berakhir jika nyawa habis.
